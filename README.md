# Bookkeeping App

一个界面清新、功能完整的 **Windows 个人收支记账桌面应用**，基于 Electron + Vue 3 开发。

所有数据保存在电脑本地，支持自动备份与一键导出 Excel；无需联网、不依赖任何云服务，账目隐私完全由自己掌握。

## ✨ 功能特性

- **快速记账**：大号金额显示、支出/收入切换、两级分类（一级图标宫格 → 二级分类）、日期与备注，几秒记一笔
- **账单明细**：按月分组的流水列表，支持修改、删除每一笔账单
- **图表统计**：支出分类占比饼图（前 5 名 + 其他）、每日趋势柱状图、收支对比卡片
- **搜索与筛选**：按关键词、分类、日期范围、金额范围查找历史账单
- **月度预算提醒**：总预算 + 分类预算，进度条红黄绿三色预警（用到 80% 提醒、超支红色告警），打开 App 与记账时同步提醒
- **分类管理**：内置两级分类体系（支出 10 大类 48 个二级、收入 5 大类 12 个二级），全部支持自定义增删改
- **导出 Excel**：一键导出 .xlsx，可用 Excel 进一步分析或打印
- **数据安全**：数据存为本地 JSON 文件（AppData 目录），每次启动自动备份（保留最近 30 份），支持手动备份/恢复

## 🛠 技术栈

| 技术 | 用途 |
|---|---|
| Electron | 桌面应用框架 |
| Vue 3（组合式 API）+ Vite | 界面开发与构建 |
| ECharts | 饼图 / 柱状图统计可视化 |
| SheetJS (xlsx) | Excel 导出 |
| electron-builder | 打包 Windows 安装包（NSIS） |

## 📐 技术要点

- 金额以「分」为整数存储，从根源上避免浮点运算误差
- 主进程负责文件读写与备份，渲染进程经 preload + IPC 访问（`contextIsolation` 开启、`nodeIntegration` 关闭），不直接接触文件系统
- 数据写入采用「临时文件 + 原子重命名」，防止写一半断电导致数据损坏
- 数据文件损坏时自动留证并重建，不会静默覆盖

## 🚀 本地运行

环境要求：[Node.js](https://nodejs.org/) 18 及以上

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev

# 构建
npm run build

# 打包 Windows 安装包（输出到 dist/）
npm run dist
```
